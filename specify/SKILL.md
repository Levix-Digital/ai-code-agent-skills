# specify

When working with specify across projects, follow these instructions:

1. **Pulling Tokens**: Use `specify pull` to download the latest design tokens. Ensure a `.specifyrc.json` configuration is present in the project root.
2. **Syncing**: Use `specify sync` to continuously sync design tokens during development.
3. **Configuration**: If `.specifyrc.json` is missing, advise the user to run `specify init` to set up the workspace.
